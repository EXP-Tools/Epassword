# 局域网分享协议与维护说明

用户操作步骤见 [用户手册](USER-GUIDE.md)。这是桌面应用显式开启的临时服务，与本机浏览器桥接和程序 API 隔离，不扩大现有 API 的监听范围。

## 生命周期与授权

- 默认关闭。只接受一个 IPv4 私有地址对端；手动输入不解析域名、不请求公网地址。
- UDP 29745 仅响应带随机请求 nonce 的服务发现，返回设备名和临时 TCP 端口。无账号、密码或密码库路径。发现信息本身不可信，连接后必须核对设备码。
- TCP 双方生成临时 X25519 密钥与随机 nonce。双方先交换握手消息的 SHA-256 承诺，再揭示并验证消息，防止看到对方参数后离线挑选自己的密钥来碰撞短码。规范化 host/client 握手消息构成 transcript；SHA-256 的前 32 位模 1000000，补前导零，作为 6 位数字核对码。握手在 60 秒内未完成双向确认则断开。
- X25519 共享秘密经 HKDF-SHA256 派生两个方向独立的 AES-256-GCM 密钥。salt 为 transcript 的 SHA-256，info 为 Epassword LAN v1。两个方向分别使用严格递增的 64 位序列构造 12 字节 nonce，重放、乱序和认证失败关闭连接。
- 6 位数字核对码必须经当面或可信通话完整比较。短码并非登录密码；每个会话必须重新核对，失败或关闭后不会自动重试。仅点击确认但不比较，无法验证对端身份。设备名称不能代替核对码。
- 服务五分钟未连接、或连接后五分钟无推送申请/成功完成则关闭。状态读取与发现不续期。关闭、锁定、系统休眠、退出或主密码变更清除连接、排队数据及会话密钥；不自动重连。

## 推送状态机

双方确认 → 本地主动选项 → offer（ID、标题、分类、内容摘要）→ 对方点击 accept / reject → accept 后才发送 items → 校验摘要和清单 → 追加到本地加密 Excel → received。

同一方向最多一个待处理申请，两个方向互相独立。每次限制 100 项 / 16 MB。无 list/search/get 等读取对方密码库的消息；未确认的 items、未知消息、修改后的清单或重复响应均拒绝。接收失败不会发送成功回执。断开后如不确定是否已保存，请在接收端确认再重发，重发会创建副本。

只发送当前字段，不发送历史密码。接收端重新分配项目与字段 ID，保留创建时间，将更新时间设为接收时间。密码历史在接收端从当前值开始。

## 测试

- npm test：设备互认、单边确认、错误设备码、双方推送、拒收、未经申请的数据、内容篡改、密文重放、发现信息、超时及密码历史持久化。
- npm run test:lan：真实 Electron 界面与独立协议对端测试，覆盖选择、确认、入库、更新时间、菜单和历史查看。
- 两台物理设备的跨系统网络、防火墙和 Wi-Fi 隔离需按用户手册手工验证；自动化使用本机独立 TCP 对端，不代表这些网络配置都已验证。

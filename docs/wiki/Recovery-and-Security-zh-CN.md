# 恢复与安全

[Wiki 首页](Home-zh-CN.md) | [English](Recovery-and-Security.md)

## 脱离 Epassword 恢复

用 Microsoft Excel 打开 .xlsx，输入同一主密码。这是 Office 文件加密，不是工作表保护。

- “密码库”保存基本凭据。
- “自定义字段”保存额外信息与 OTP 密钥 / 链接，通过项目 ID 关联。
- “使用说明”记录格式和恢复方法。

OTP 设置材料可导入兼容验证器。Excel 可以读取它，但不会自动计算实时验证码。

主密码遗忘后无法重置；工作簿丢失时需要备份。

## 备份

每次保存将上一版加密文件保留为 .xlsx.bak。复制为新的 .xlsx 文件名后即可打开。更改主密码后，上一份备份仍需要旧密码。

只保留一个前序版本，不是永久历史。请另外备份。移入回收站也不代表内容已擦除。

## 编辑与冲突

不要同时用 Excel 和应用编辑同一文件。发现外部修改后，锁定并重新打开，加载新内容。

保留工作表名称、表头和 ID。数据表中的公式单元格不受支持。应用重写时不保留额外工作表和用户添加的格式。

旧版程序可能丢弃自定义字段，使用新字段后不要降级写入。

## 安全边界

没有云同步或额外应用恢复密钥。密码与 OTP 设置密钥在同一个加密文件中；同时掌握文件和主密码的人可恢复两者。

解锁后数据存在进程内存中，JavaScript 字符串和系统剪贴板历史无法保证物理擦除。应用未经过独立安全审计，不宣称与 1Password 同等安全。

本地检查只识别较短和重复密码，不查询在线泄露。暂不支持浏览器自动填充、附件、共享或通行密钥。

Windows Excel 独立恢复已验证，Excel for Mac 尚未验证；应明确说明实际测试平台。

# Epassword Wiki

**English** | [简体中文](Home-zh-CN.md)

Epassword is a local Electron password manager whose vault is a password-encrypted Excel file. Your master password is the workbook's file-open password.

## Guides

- [Getting started](Getting-Started.md): install, create a vault and move between devices.
- [Daily use and OTP](Daily-Use-and-OTP.md): copy, generate, customize fields and scan authenticator QR codes.
- [Recovery and security](Recovery-and-Security.md): backups, Excel recovery and security boundaries.
- [Development and troubleshooting](Development-and-Troubleshooting.md): architecture, test commands, packaging and common failures.

## Platform status

Windows x64 has been tested locally. Mac Intel and Apple Silicon support and build workflows are implemented, but native Mac validation remains pending. Default Mac builds are development packages, not Apple-notarized distributions.

## Where this wiki lives

These pages are versioned with the project under docs/wiki so they can be read even when GitHub's separate Wiki feature is unavailable. The repository is private; enabling its native Wiki was attempted, but GitHub continued to report has_wiki=false. Repository visibility has not been changed.

[GitHub Wiki availability](https://docs.github.com/en/communities/documenting-your-project-with-wikis) depends on the account/organization plan for private repositories. Once that feature is available and initialized, these pages can be migrated. Their current published location is this repository's documentation directory.

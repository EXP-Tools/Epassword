# Chrome 浏览器插件

[English](Browser-Extension.md) | **简体中文**

Manifest V3 插件连接本机运行的 Epassword 桌面端，适用于 Windows 和 macOS。密码仍保存在加密 Excel 密码库中，不需要安装 Excel、云服务或 Native Messaging 宿主。


推荐使用 Epassword-Setup 一体安装包：Windows 运行 install.cmd，Mac 运行 bash install.command，同时安装桌面与插件，再按 setup.html 启用 Chrome 插件并配对。[安装说明](../../INSTALL.zh-CN.md)。


## 安装与配对

1. 安装或构建更新后的桌面端并解锁密码库。旧桌面程序不含浏览器连接接口。
2. 下载构建产物中的 Chrome ZIP 并解压，或直接使用仓库的 **extension** 文件夹。将文件夹放在固定位置。
3. 打开 Chrome 的 **chrome://extensions**，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。将 Epassword 固定到工具栏。
4. Epassword 中打开 **设置与恢复 → 浏览器插件 → 生成配对码**，使用 Ctrl+C（Windows）或 Command+C（Mac）复制已选中的配对码。
5. 打开一个 HTTPS 网站，点击工具栏 Epassword，展开「连接桌面端」，粘贴配对码并点击「配对」。安装前已打开的网页需要刷新。

一次桌面会话仅配对一个插件安装实例。再次生成配对码会撤销旧连接。配对码是随机连接凭据，不是主密码；重启桌面端或 Chrome 后需要重新配对，同次运行中锁定再解锁无需重新配对。「关闭浏览器连接」会立即撤销访问并关闭监听。

## 填充登录账号

在登录项目的网址字段或额外的 URL 字段中保存完整 HTTPS 地址。按 HTTPS 主机名和端口精确匹配，忽略路径；不会自动匹配父域名、其他子域名。合法的其他登录域名可单独添加 URL 字段。

点击插件中的账号即可填充可见的用户名和密码框。勾选「此网站单账号自动填充」，刷新后仅有一个匹配账号时自动填充；多个账号需要选择。自动填充不覆盖已有输入，也不会提交登录表单。

不填充注册/新密码表单、多个密码框的表单、HTTP 页面、跨域提交表单、iframe 或浏览器内部页面。已归档、已删除项目不参与匹配。Shadow DOM、自定义控件、先用户名后密码的分步登录可能需要从桌面端复制。

## 注册时保存

标准 HTML 注册表单通过真实点击或提交，且含 autocomplete=new-password 或两个一致的密码框时，会生成临时待保存信息。页面提示打开工具栏插件，插件角标显示 **!**。仅已配对的插件会暂存信息，提示条不会显示用户名或密码。

确认网站注册成功后，打开插件选择「保存到 Epassword」，桌面端会弹出原生确认框，展示网站和用户名。两分钟内选择「保存新项目」，才会写入加密 Excel。桌面端获得焦点时 Chrome 弹窗可能关闭，确认后可重新打开。

插件不判断网站是否注册成功，不覆盖已有账号；相同的有效账号密码不会重复新增。取消或忽略不改变密码库。临时注册信息五分钟后过期，关闭标签页、重启浏览器、重载插件或断开连接也会删除。过期清理最多延后一轮定时检查，但过期信息不能保存。

非标准 JavaScript 注册控件、缺少新密码提示或确认框的表单、iframe 注册页可能无法识别，请在桌面端手动添加。

## 连接与隐私

桌面端默认不开启接口，仅生成配对码后监听 **127.0.0.1:29743**，检查 Host、插件身份和配对凭据，拒绝普通网页来源。访问必须携带配对码且密码库已解锁。列表不返回密码，只为指定的精确匹配账号提供填充密码，没有远程服务器。

插件需要 HTTPS 网页权限检测表单、本机接口访问权限、存储权限、当前标签页权限及过期清理定时器。网站自动填充偏好保存在本地。配对码和临时注册密码保存在仅插件上下文可访问的内存 storage.session 中，不写入 storage.local/sync。与其他基于 DOM 的填充方式相同，填入网页后的值可被该网页脚本读取。

此功能不能抵御已控制系统账号、浏览器、插件或目标网站的恶意软件。连接接口和插件尚未经过独立安全审计。不要转发本机端口或分享配对码。

## 排障与开发

- **无法连接：** 启动更新后的桌面端、解锁并重新配对。若 29743 端口被占用，关闭另一个 Epassword 实例或占用程序。
- **无匹配项：** 检查 HTTPS、主机名、端口、登录类型和归档/回收站状态。
- **无法填充：** 安装后刷新网页，并检查 iframe、分步登录、新密码表单等限制。
- **密码库已锁定：** 回到桌面端解锁，锁定期间不能读取密码。
- **保存取消或超时：** 确认网站注册成功后重新发起；连接中断时先检查桌面密码库再重试。
- **Mac：** 安装文件夹与配对步骤相同。Windows 集成已在本机测试，Mac 原生测试仍待完成。

~~~sh
npm run pack:extension
npx playwright install chromium
npm run test:browser
~~~

ZIP 位于 release/Epassword-Chrome-1.2.0.zip。测试使用独立浏览器配置、模拟 HTTPS 网页和测试密码库，不访问个人 Chrome 数据。无法下载时，可用 EPASSWORD_TEST_CHROME 指定已有 Chrome for Testing / Chromium 可执行文件；正式版 Chrome 可能不允许命令行加载插件。EPASSWORD_TEST_RUNTIME 可指定打包后的桌面端程序。

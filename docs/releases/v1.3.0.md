# Epassword 1.3.0

本次发布仅面向 Windows x64、macOS Intel x64 和 Apple Silicon arm64 桌面端。

## 新增功能

- **局域网分享**：搜索服务或填写 IPv4 地址和端口，核对 6 位数字设备码，双方确认后建立临时加密连接。支持双向多选 / 全选推送，接收方同意后才发送内容；不能浏览或提取对方其他项目。
- **自动关闭**：5 分钟未连接，或配对后 5 分钟无推送动作自动关闭；也可手动断开。锁定、休眠、退出、修改主密码均断开。
- **接收时间**：收到分享的项目使用新 ID 追加，最后编辑时间更新为接收时间。
- **项目右键菜单**：复制项目、移动分类、归档 / 取消归档，以及二次确认后的彻底删除。
- **密码历史**：记录项目密码和自定义密码字段成功保存后的版本与时间，支持显示、复制，并保存在同一加密 Excel 的「密码历史」工作表。
- **文档与预览**：更新中英文 README、安装指南、图文用户手册及 GitHub Pages 局域网交互演示。

## 下载与升级

优先下载对应平台的 Epassword-Setup ZIP：完整解压后，Windows 运行 install.cmd，Mac 运行 bash install.command。一体包包含桌面应用、Chrome 插件文件、API 客户端和使用文档。

升级前备份密码库并关闭应用，安装目录外的原有 Excel 文件和主密码继续可用。局域网分享双方需要 1.3 或更新版本。

密码历史不包含主密码、临时分享密码和导出密码。Excel 导出会保留历史，未加密导出也会包含旧密码；单项密文分享和局域网分享不发送历史。保存历史后请勿使用旧版本编辑同一文件，旧版保存会丢弃历史工作表。

Chrome 仍需手动启用 / 重新加载并配对。Mac 应用未经 Apple 公证。自动化覆盖 Windows 桌面交互、双端协议测试及 macOS 构建 / 冒烟测试；两台实体设备的网络、防火墙和 Excel 原生兼容性仍需实机验证。

## English

Desktop-only release for Windows x64 and macOS Intel / Apple Silicon.

- LAN sharing with discovery/direct IPv4 entry, six-digit mutual verification, encrypted bidirectional multi-item pushes and explicit recipient consent. No remote vault browsing or arbitrary reads.
- Five-minute connection/push inactivity timeout, manual disconnect and disconnect on lock, sleep, exit or master-password change.
- Received items receive new IDs and a current last-edited timestamp.
- Item context menu: duplicate, change category, archive/unarchive and confirmed permanent deletion.
- Timestamped history for item and custom Password fields, stored in the encrypted Excel workbook and available for reveal/copy.
- Updated bilingual guides, screenshots and interactive product preview.

Back up your vault and close the app before running the matching combined Setup installer. Both peers need version 1.3 or later. Existing vaults and master passwords remain valid. Excel exports preserve history; plain exports expose it. LAN and encrypted single-item sharing exclude history. Older app versions discard the history worksheet when saving.

Chrome activation/reloading and pairing remain manual. Mac packages are not Apple-notarized. Automated local/network-protocol and macOS smoke tests do not replace physical-device LAN/firewall or native Excel compatibility testing.
